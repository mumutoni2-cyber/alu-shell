# Loops, Conditions and Parsing

Bash scripts practicing loops, conditions, and parsing.

## Requirements

- The first line of every script is `#!/usr/bin/env bash`
- The second line of every script is a comment explaining what it does
- All scripts must be executable

## Tasks

| File | Description |
|------|-------------|
| `1-for_best_school` | Displays "Best School" 10 times using a `for` loop. |
| `2-while_best_school` | Displays "Best School" 10 times using a `while` loop. |
| `3-until_best_school` | Displays "Best School" 10 times using an `until` loop. |
